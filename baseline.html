2. Normalization & calibrator

These settings follow the ΔΔCt approach used in your workbook.

Reference mean Ct = mean(reference technical replicates)
ΔCt = mean(target Ct) − mean(reference Ct)
ΔΔCt = ΔCt(condition) − ΔCt(calibrator, same trial)
Relative expression = 2−ΔΔCt
log₂FC = log₂(relative expression) = −ΔΔCt

3. Sample → condition mapping

The full sample name is used as the condition by default. Edit the condition column when samples contain replicate IDs or extra labels.
